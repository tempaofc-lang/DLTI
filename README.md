# DLTI 人格测试

> 开学了，入秋了，于是 DLTI 来了。

一个开源的娱乐性**地理人格测试**。把人性折叠进山川湖海——你的性格不是一道公式，而是一块地貌。

基于 B站UP主 [@蛆肉儿串儿](https://space.bilibili.com/417038183) 的原创测试，由 TEMPA 再创作。测试通过 **15 个维度、五大模型**描摹你，再把你匹配到一座地标、一类地貌：富士山的克制与内焰、龙卷风的来去如风、三角洲的润物无声、克拉通的千年不动……最终你会得到一张属于自己的「地理名片」。

## 五大方向

15 个评估维度 = **五大方向 × 每个方向 3 个维度**。五个方向分别回答：你和自己、和情感、和世界、和行动、和人群的关系。

### 🌱 自我模型（S1–S3）—— 你和自己的关系

| 维度 | 它想知道的 |
| --- | --- |
| S1 自尊自信 | 面对他人评价时，你对自己的认可度 |
| S2 自我清晰度 | 你对自己有多了解，内心频道清不清楚 |
| S3 核心价值 | 是什么在驱动你：舒服安全，还是目标成长 |

### 💞 情感模型（E1–E3）—— 你在亲密关系里的状态

| 维度 | 它想知道的 |
| --- | --- |
| E1 依恋安全感 | 你对关系稳定性的信任程度 |
| E2 情感投入度 | 认定之后，你愿意投入多少 |
| E3 边界与依赖 | 亲密与独立之间，你怎么平衡 |

### 🧭 态度模型（A1–A3）—— 你看待世界的方式

| 维度 | 它想知道的 |
| --- | --- |
| A1 世界观倾向 | 先怀疑还是先相信，世界在你眼里是善是恶 |
| A2 规则与灵活度 | 秩序感 vs 变通，规则能不能绕 |
| A3 人生意义感 | 你做事有没有方向，意义感是否在线 |

### ⚡ 行动驱力模型（Ac1–Ac3）—— 你做事的风格

| 维度 | 它想知道的 |
| --- | --- |
| Ac1 动机导向 | 驱动你的是避险求稳，还是进取求成 |
| Ac2 决策风格 | 拍板快不快，脑内会议开几场 |
| Ac3 执行模式 | 执行力的节奏和持久度，是不是 ddl 战神 |

### 🫂 社交模型（So1–So3）—— 你与人群相处的方式

| 维度 | 它想知道的 |
| --- | --- |
| So1 社交主动性 | 你愿意主动打开场子，还是等人来敲门 |
| So2 人际边界感 | 靠太近会后退半步，还是想把人划进内圈 |
| So3 表达与真实度 | 表达够不够直接，真实感会不会分层发放 |

## 特性

- 🌍 **27 种地理人格** — 25 种标准类型 + 2 种特殊人格（隐藏彩蛋 / 保底兜底）
- 🗺️ **七大类型区** — 高能量/爆发区、流动/社交型、内敛/沉淀型、周期/情绪波动型、稳定/抗压型、人文/生活方式型、混沌/不可预测型
- 📊 **15 个评估维度** — 自我、情感、态度、行动驱力、社交五大模型
- 🎯 **曼哈顿距离匹配** — 基于 15 维向量的地理匹配算法，距离越近越像
- 🥷 **隐藏彩蛋** — 特定选项触发隐藏人格，覆盖正常匹配
- 📱 **移动端优先** — 响应式设计，手机体验友好
- 🔧 **易于定制** — 数据与代码分离，改 JSON 即可打造你自己的测试

## 评分算法

1. **求和**：每维度 2 题分值相加（范围 2-6）
2. **分级**：≤3 → L（低），4 → M（中），≥5 → H（高）
3. **向量化**：L=1, M=2, H=3，生成 15 维数值向量
4. **匹配**：计算用户向量与每种地理人格的曼哈顿距离
5. **排名**：距离升序 → 精准命中降序 → 相似度降序
6. **特殊覆盖**：隐藏人格彩蛋 > 正常匹配 > 保底人格（相似度 < 60%）
